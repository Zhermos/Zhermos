## 🚀 วิธีนำไปใส่ใน GitHub Profile README

1. สร้าง Repository ชื่อเดียวกับ Username ของคุณ: `https://github.com/Zhermos/Zhermos` (ถ้ามีอยู่แล้วให้เข้าไปที่ repo นั้น)
2. อัปโหลดไฟล์ `banner.svg` (หรือ `banner-pure.svg`) เข้าไปใน Repository
3. ใส่โค้ด Markdown ด้านล่างนี้ไว้บนสุดของไฟล์ `README.md`:

```markdown

</p>
```

*(หรือหากต้องการใช้แบบ Native Pure Vector ให้เปลี่ยนเป็น `src="banner-pure.svg"`)*
